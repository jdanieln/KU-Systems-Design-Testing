# Registro de Asistencia y Verificación de Entorno

En esta carpeta se registran las confirmaciones de asistencia y configuración del entorno de desarrollo de cada estudiante.

Cada estudiante contará con su propio archivo en formato:
`asistencia/<usuario_github>.md`

### Formato esperado del archivo:
- **Estudiante / Usuario:** <usuario>
- **Fecha:** <YYYY-MM-DD HH:mm>
- **Versión de Python:** <salida de python3 --version>
- **Versión de Node.js:** <salida de node --version>
- **Estado del Entorno:** Configurado y verificado
